# Python Quiz Application

A beginner-friendly command-line Quiz Application built using Python.

This project asks multiple-choice questions, checks answers, calculates scores, and displays the final performance.

---

##  Features

* Multiple-choice quiz questions
* Score tracking system
* Instant correct/wrong feedback
* Final percentage calculation
* Performance evaluation message

---

##  Technologies Used

* Python
* Lists & Dictionaries
* Loops
* Conditional Statements
* User Input Handling

## How to Run

1. Install Python
2. Download or clone this repository
3. Open terminal in project folder
4. Run:

```bash id="tzqz7n"

```
