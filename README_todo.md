# PROGRAMMING-IN-PYTHON
#  Python To-Do List Application

A simple command-line To-Do List application built using Python.

This project allows users to add, view, and remove tasks while storing them in a text file for future use.

---

##  Features

* View all tasks
* Add new tasks
* Remove completed tasks
* Save tasks permanently using file handling
* Beginner-friendly Python project

---

##  Technologies Used

* Python
* File Handling
* Functions
* Lists
* Loops & Conditionals

---

##  Project Structure

```bash
todo-list-python/
│
├── main.py
├── tasks.txt
└── README.md
```

---

##  How to Run

1. Install Python on your computer
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the following command:

```bash
python main.py
```
